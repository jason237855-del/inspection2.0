# 驗屋費用卡片內懸浮「立即預約」按鈕

## 目標
將驗屋費用區塊的「立即預約」改為在每張價格卡片內、滑鼠移入時於右下角顯示，讓 CTA 與方案直接對應，不再使用區塊中央的獨立橫幅。

## 修改範圍
- **src/components/Pricing.tsx**：
  - 移除目前位於價格卡片下方的中央獨立 CTA 橫幅。
  - 為每張價格卡片加入 hover 狀態（或純 CSS group-hover）。
  - 滑鼠移入卡片時，在卡片內右下角顯示「立即預約」按鈕。
  - 按鈕點擊後開啟官方 LINE 連結 `https://lin.ee/XzyRTbH`。
  - 保留 reduced-motion 與響應式處理；觸控裝置上建議預設顯示或透過 active 狀態可見，避免 hover-only。

## 設計方向
- 按鈕使用圓角膠囊樣式，尺寸與現有按鈕語言一致。
- 根據卡片主色調調整按鈕配色：
  - 主色卡片（新成屋）：使用 `primary-foreground` 背景配 `primary` 文字，或反轉為主色背景配主色前景文字。
  - 白色卡片（中古屋）：使用 `bg-primary text-primary-foreground`。
- 進場動畫輕微（fade + scale），不影響卡片內容閱讀。
- 按鈕固定在卡片右下角，與卡片內容保持適當間距。

## 驗收標準
1. 價格卡片下方不再出現中央獨立 CTA 橫幅。
2. 滑鼠移入每張價格卡片時，右下角出現「立即預約」按鈕。
3. 點擊按鈕正確開啟官方 LINE。
4. 桌面與手機版卡片排版正常，無跑版。
5. TypeScript 檢查與預覽畫面無錯誤。
