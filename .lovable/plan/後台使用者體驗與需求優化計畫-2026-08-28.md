# 後台使用者體驗與需求優化計畫

## 目標
針對「預約紀錄管理」與「日曆名額管理」兩大區塊進行後台優化，並新增「建案名稱」欄位與「新預約即時提醒」。

## 具體修改項目

### 1. 資料庫：新增建案名稱欄位
- 在 `booking_requests` 增加 `project_name`（text，可空白）。
- 更新前端預約表單，讓屋主在第二步聯繫資訊中填寫「建案名稱」。
- 該欄位會帶入 LINE 預約訊息與後台預約紀錄。

### 2. 預約紀錄管理強化
- **搜尋**：依姓名、電話、建案名稱、地址關鍵字搜尋。
- **篩選**：狀態（待確認 / 已確認 / 已取消）、檢測類型、房屋類型、地區、日期區間。
- **排序**：依建立時間 / 期望檢測日期排序。
- **分頁**：每頁 10 筆，避免資料過多時表格過長。
- **詳情彈窗**：點擊預約列可開啟詳細資料，內含聯繫資訊、地址、建案名稱、備註與狀態變更。
- **匯出 CSV**：可將篩選後的預約資料匯出為 CSV，方便對帳或列印。

### 3. 日曆與名額管理強化
- **日曆上顯示預約數**：每日格子直接顯示「已預約 / 可預約名額」。
- **快速切換月份**：保留左右箭頭，並加入「回到今天」按鈕。
- **批量設定**：可一次選取多個日期，統一設定名額或關閉預約。
- **假日一鍵關閉**：提供按鈕快速關閉當月所有週六日或國定假日（後續可再擴充國定假日清單）。

### 4. 新預約即時提醒
- 在 `/admin` 頁面掛載 Supabase Realtime 訂閱，監聽 `booking_requests` 新增事件。
- 有新預約時，右上角顯示 toast 通知與「新預約」badge。
- 自動重新整理預約列表與日曆數據，無需手動重新整理頁面。

### 5. 桌面版介面微調
- 表格欄位寬度與對齊優化，適合電腦大螢幕。
- 篩選列置於表格上方，採用水平排列。
- 強化空狀態（無資料時）提示。

## 技術實作重點
- 資料庫變更透過 migration 工具執行。
- 使用 Supabase Realtime 監聽新預約。
- 維持現有 RLS 與 admin 權限架構，不影響安全性。
- 所有 UI 使用現有 shadcn/ui 元件與設計 token，保持風格一致。
