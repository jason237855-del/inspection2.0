## 1. 新成屋驗屋要檢查什麼？六大系統驗屋重點

- **slug**：`new-home-inspection-checklist`
- **分類**：驗屋知識
- **seoTitle**：新成屋驗屋要檢查什麼？六大系統驗屋重點整理｜診斷筆記
- **metaDescription**：新成屋交屋前驗屋，不只是看牆面有沒有刮傷。整理電氣、給排水、防水、建築土建、設備與環境六大系統的檢查重點，讓你交屋前知道該看什麼。

**開頭**
新成屋看起來乾淨漂亮，不代表沒有問題。施工過程中的水電、防水、泥作與設備安裝，很多問題要靠實際測試才看得出來。驗屋的目的，是在正式交屋前把問題記錄清楚，請建商修繕，而不是入住後才發現。

**一、電氣：功能正常，還要看安全**
- 開關、插座是否都有電、接觸是否穩固。
- 配電箱迴路標示是否清楚，漏電斷路器動作是否正常。
- 全戶電壓與相位是否正常（【請確認：你們的檢測項目名稱】）。
- 弱電（網路、電話、電視）是否通。

**二、給排水：不只是水有出來**
- 各水龍頭水壓、冷熱水是否正常。
- 衛浴、廚房排水是否順暢，有無異味、積水。
- 地面洩水坡度是否往地漏方向。

**三、防水：看不見的地方最重要**
- 牆面、天花板有無水痕、壁癌、油漆起泡。
- 浴室、陽台、窗框周圍的防水處理。
- 必要時用儀器（含水率、紅外線熱像）輔助判讀，儀器異常不等於一定漏水，需要交叉確認。

**四、建築土建：地壁磚與垂直水平**
- 磁磚空心（用敲擊或儀器檢測）、縫隙與平整度。
- 牆面、地面的垂直與水平誤差。
- 門窗框安裝是否歪斜，開關是否順。

**五、設備：門窗、廚具、衛浴**
- 門窗開關與鎖具功能、玻璃有無刮傷。
- 廚具、衛浴設備功能與外觀。
- 防火門標章與膠條【請確認】。

**六、環境：入住前的空氣與水質**
- 室內甲醛、PM2.5 等空氣品質；噪音；屋內水質。

**下一步**
把所有缺失拍照、標示位置、列成清單，在建商規定的期限內通知，並在修繕後**複驗**，確認真的改善才簽收。

## 2. 驗屋什麼時候做？新成屋交屋前的時間點與流程

- **slug**：`when-to-inspect-new-home`
- **分類**：驗屋知識
- **seoTitle**：新成屋驗屋什麼時候做？交屋前的時間點與流程｜診斷筆記
- **metaDescription**：新成屋驗屋最好在正式交屋、簽收與尾款之前完成。說明驗屋時間點、建商通知後該怎麼安排，以及發現缺失後的處理順序。

**開頭**
最常見的問題是：「建商通知我交屋了，我什麼時候驗？」原則是**在正式簽收交屋前**。簽收之後，責任認定會變複雜，也比較難要求建商處理。

**時間點**
1. **建商通知驗屋／交屋時**：先確認建商規定的驗屋期間與修繕流程。
2. **預約驗屋**：建議在通知後儘快預約，因為假日與交屋旺季時段會滿。
3. **驗屋當天**：現場檢測並標示缺失。
4. **提交缺失清單**：向建商提出，約定修繕期限。
5. **複驗**：修繕後確認改善，再進入簽收與後續程序。

**要準備什麼**
- 權狀、平面圖、建材表、客變資料與交屋文件。
- 【請確認：屋主需不需要全程到場】

**保固要看合約**
交屋後的保固期間，一般以買賣契約與內政部公布的定型化契約範本為準（常見說法是結構部分較長、設備與固定建材較短）【請確認：法規年限請你核對後再決定要不要寫具體年數】。

**下一步**
提前弄清楚建商的交屋流程、驗屋時限與修繕方式，再預約驗屋時間。

## 3. 中古屋買前驗屋要看什麼？

- **slug**：`resale-home-inspection-what-to-check`
- **分類**：中古屋
- **seoTitle**：中古屋買前驗屋要看什麼？屋況與風險的判斷重點｜診斷筆記
- **metaDescription**：中古屋和新成屋的檢測重點不同。整理買房前該看的滲漏水跡象、管線與設備狀態、老化程度，以及驗屋能做到與做不到的事。

**開頭**
中古屋不像新成屋有施工缺失，而是要判斷「現在的狀態」與「接下來要花多少維護成本」。驗屋的價值是在下訂或簽約之前，把風險看清楚。

**重點**
- **滲漏水跡象**：牆面、天花板水痕、壁癌、油漆膨起；浴室、陽台與窗框周邊。
- **管線與設備**：給排水管、電線與配電箱的年代與狀態；熱水器與通風（可連結：中古屋熱水器通風那篇）。
- **老化與使用痕跡**：磁磚、地板、門窗五金。
- **結構相關現象**：明顯裂縫類型與位置，只能觀察記錄，**是否有結構安全疑慮需要專業結構技師判斷**【請確認：你們的說法】。

**驗屋做不到的事**
現場檢測只能判斷可見與可測的範圍，無法保證牆內或隱蔽處完全沒有問題（可連結：驗屋的限制那篇）。

**下一步**
簽約前預約驗屋，依報告中的風險等級，決定要議價、要求賣方先修繕，或重新考慮。

## 4. 驗屋當天流程：從進門到拿到報告

- **slug**：`inspection-day-what-to-expect`
- **分類**：驗屋知識
- **seoTitle**：驗屋當天流程：要花多久、屋主要做什麼、怎麼拿到報告｜診斷筆記
- **metaDescription**：第一次驗屋不知道當天會發生什麼？說明驗屋當天的流程、所需時間、屋主需要準備與配合的事，以及報告如何交付。

**開頭**
很多屋主第一次驗屋會擔心「要不要全程陪著？」「要花多久？」把流程講清楚，預約時會更安心。

**流程（依你們實際做法修改）**
1. **到場確認**：核對地址、坪數與檢測範圍。【請確認】
2. **逐區檢測**：從電氣、給排水、防水、建築到設備逐項確認，用儀器輔助。
3. **現場標示缺失**：在缺失位置做標記並拍照。
4. **當場說明重點**：屋主到場的話，可以直接了解主要問題。【請確認】
5. **報告交付**：官網流程頁寫「48 小時內交付圖文報告」（【請確認目前是否仍是這個時效】）。

**時間**：依坪數與檢測項目而定【請確認：一般幾小時】。

**屋主需要準備**
權狀、平面圖、建材表、客變與交屋文件；確保水電已開通【請確認】。

**下一步**
拿到報告後，依風險等級與位置，向建商提出修繕要求，修繕完成後安排複驗。

## 5. 社區一起驗屋（團購驗屋）怎麼運作？划算嗎？

- **slug**：`group-home-inspection-how-it-works`
- **分類**：驗屋知識
- **seoTitle**：社區團購驗屋怎麼運作？同建案多戶一起驗屋的好處與流程｜診斷筆記
- **metaDescription**：同一個建案多戶一起預約驗屋，達成戶數可享團報折扣。說明團報的運作方式、每戶如何各自預約，以及適合什麼情況。

**開頭**
同一個社區的住戶通常在差不多的時間交屋。多戶一起預約驗屋，對屋主和驗屋團隊都有好處：屋主可以享折扣，也能互相分享建商的常見缺失。

**運作方式（以官網目前規則為準）**
- 在官網「建案團報」找到你的建案，按「加入團報」。
- **每戶各自填寫預約**，自己選日期與時段，不需要全部同一天。
- 同建案報名戶數達到門檻，全團享團報折扣；**目前的門檻與折數請以官網為準**（後台可調整，寫進文章要用「以官網公告為準」的說法，避免之後過時）。
- 團報不與 LINE 好友折扣並用。
- 已取消的訂單不計入戶數。

**適合誰**
同建案、交屋時間接近的鄰居；想一起比較各戶缺失的社區群組。

**找不到你的建案？**
可以在官網提出新建案，審核上架後邀請鄰居一起加入。

**下一步**
先看官網團報專區有沒有你的建案，有的話直接加入；沒有就提出建案，並把連結分享給社區群組。
