## 1. 新成屋驗屋要檢查什麼？六大系統驗屋重點

- **slug**：`new-home-inspection-checklist`
- **分類**：驗屋知識
- **seoTitle**：新成屋驗屋要檢查什麼？六大系統驗屋重點整理｜診斷筆記
- **metaDescription**：新成屋交屋前驗屋，不只是看牆面有沒有刮傷。整理電氣、給排水、防水、建築土建、設備與環境六大系統的檢查重點，讓你交屋前知道該看什麼。

**開頭**
新成屋看起來乾淨漂亮，不代表沒有問題。〔核對〕施工過程中的水電、防水、泥作與設備安裝，很多問題要靠實際測試才看得出來。〔核對〕驗屋的目的，是在正式交屋前把問題記錄清楚，請建商修繕，而不是入住後才發現。〔核對〕

**一、電氣：功能正常，還要看安全**
- 開關、插座功能與外觀是否完整。〔官網〕
- 配電箱迴路功能與施工完整性、電箱單線圖圖面審核。〔官網〕
- 全戶電壓相位與漏電斷路檢測。〔官網〕
- 全戶弱電系統（網路、電話、電視）檢測。〔官網〕

**二、給排水：不只是水有出來**
- 全戶水壓、給水與排水系統檢測。〔官網〕
- 衛浴、廚具設備的給水與排水檢測。〔官網〕
- 衛浴與陽台洩水坡度是否往地漏方向。〔官網〕
- 有無異味、積水。〔核對〕

**三、防水：看不見的地方最重要**
- 牆面、天花板、衛浴空間、門窗框的滲漏水檢測。〔官網〕
- 以混凝土水分比、熱顯像儀輔助判讀。〔官網〕
- 儀器異常不等於一定漏水，需要交叉確認。〔官網：與現有筆記〈熱像儀看到異常，就代表房子漏水嗎？〉一致〕

**四、建築土建：地壁磚與垂直水平**
- 壁磚、地磚空心與外觀完整性檢測。〔官網〕
- 牆面垂直水平、室內地面水平檢測。〔官網〕
- 牆面天花板油漆施工品質、木地板與踢腳板施工。〔官網〕
- 門窗框安裝是否歪斜。〔核對〕

**五、設備：門窗、廚具、衛浴**
- 門扇窗戶外觀與功能／安裝檢測。〔官網〕
- 廚具、衛浴設備功能及安裝完整性。〔官網〕
- 淋浴拉門功能及安裝。〔官網〕
- 防火門標章與膠條檢查。〔官網〕

**六、環境：入住前的空氣與水質**
- 全室甲醛、PM2.5、噪音、電磁波與屋內水質檢測。〔官網〕

**下一步**
把所有缺失拍照、標示位置、列成清單。〔核對〕在建商規定的期限內通知。〔核對〕修繕後安排複驗，確認缺失確實改善。〔官網：服務流程第 5 步〕

## 2. 驗屋什麼時候做？新成屋交屋前的時間點與流程

- **slug**：`when-to-inspect-new-home`
- **分類**：驗屋知識
- **seoTitle**：新成屋驗屋什麼時候做？交屋前的時間點與流程｜診斷筆記
- **metaDescription**：新成屋驗屋最好在正式交屋、簽收與尾款之前完成。說明驗屋時間點、建商通知後該怎麼安排，以及發現缺失後的處理順序。

**開頭**
最常見的問題是：「建商通知我交屋了，我什麼時候驗？」原則是在正式簽收交屋前。〔核對〕簽收之後，責任認定會變複雜，也比較難要求建商處理。〔核對：這是法律與實務判斷，請確認你想不想這樣寫〕

**時間點**
1. 建商通知驗屋／交屋時，先確認建商規定的驗屋期間與修繕流程。〔核對〕
2. 預約驗屋：建議通知後儘快預約，假日與交屋旺季時段會滿。〔核對〕
3. 驗屋當天現場檢測並標示缺失。〔官網：服務流程第 3 步〕
4. 提交缺失清單向建商提出，約定修繕期限。〔核對〕
5. 修繕後複驗，確認改善再進入簽收與後續程序。〔官網：服務流程第 5 步〕

**要準備什麼**
- 權狀、平面圖、建材表與交屋文件。〔官網：服務流程第 2 步〕
- 客變資料。〔核對：官網只寫「交屋文件」，「客變」是我加的〕
- 屋主需不需要全程到場。〔待確認〕

**保固要看合約**
交屋後的保固期間，一般以買賣契約與內政部公布的定型化契約範本為準。〔待確認：法規年限我沒有核對，建議不要寫具體年數，只寫「以合約為準」〕

**下一步**
提前弄清楚建商的交屋流程、驗屋時限與修繕方式，再預約驗屋時間。〔核對〕

## 3. 中古屋買前驗屋要看什麼？

- **slug**：`resale-home-inspection-what-to-check`
- **分類**：中古屋
- **seoTitle**：中古屋買前驗屋要看什麼？屋況與風險的判斷重點｜診斷筆記
- **metaDescription**：中古屋和新成屋的檢測重點不同。整理買房前該看的滲漏水跡象、管線與設備狀態、老化程度，以及驗屋能做到與做不到的事。

**開頭**
中古屋不像新成屋有施工缺失，而是要判斷「現在的狀態」與「接下來要花多少維護成本」。〔核對〕驗屋的價值是在下訂或簽約之前，把風險看清楚。〔核對〕

**重點**
- 滲漏水跡象：牆面、天花板水痕、壁癌、油漆膨起，浴室、陽台與窗框周邊。〔核對：與現有筆記〈牆面水分偏高〉〈下雨後窗邊出現水漬〉的觀念一致〕
- 管線與設備：給排水管、電線與配電箱的年代與狀態。〔核對〕
- 熱水器與通風。〔官網：現有筆記〈中古屋的熱水器與排氣〉；文章內連結過去〕
- 老化與使用痕跡：磁磚、地板、門窗五金。〔核對〕
- 結構相關現象：明顯裂縫的類型與位置，只能觀察記錄，是否有結構安全疑慮需要結構技師判斷。〔待確認：你們對結構的說法與分界〕

**驗屋做不到的事**
現場檢測只能判斷可見與可測的範圍，無法保證牆內或隱蔽處完全沒有問題。〔官網：與現有筆記〈驗屋真的可以找出房子所有的問題嗎？〉一致；文章內連結過去〕

**下一步**
簽約前預約驗屋，依報告中的風險等級，決定要議價、要求賣方先修繕，或重新考慮。〔核對〕

## 4. 驗屋當天流程：從進門到拿到報告

- **slug**：`inspection-day-what-to-expect`
- **分類**：驗屋知識
- **seoTitle**：驗屋當天流程：要花多久、屋主要做什麼、怎麼拿到報告｜診斷筆記
- **metaDescription**：第一次驗屋不知道當天會發生什麼？說明驗屋當天的流程、所需時間、屋主需要準備與配合的事，以及報告如何交付。

**開頭**
很多屋主第一次驗屋會擔心「要不要全程陪著？」「要花多久？」把流程講清楚，預約時會更安心。〔核對〕

**流程**
1. 到場確認：核對地址、坪數與檢測範圍。〔待確認：你們實際是否這樣做〕
2. 逐區檢測：以專業儀器逐區檢查結構、水電、防水、門窗與空氣品質。〔官網：服務流程第 3 步〕
3. 現場標示缺失並拍照。〔官網：服務流程第 3 步「現場標示缺失」；拍照為〔核對〕〕
4. 當場說明重點給屋主。〔待確認：你們是否會這樣做〕
5. 48 小時內交付圖文報告，標註缺失位置、風險等級與建議改善方式。〔官網：服務流程第 4 步，**請確認目前時效是否仍是 48 小時**〕

**時間**
依坪數與檢測項目而定，一般需要幾小時。〔待確認：請填實際的時間範圍，或刪掉這段〕

**屋主需要準備**
- 權狀、平面圖、建材表與交屋文件。〔官網：服務流程第 2 步〕
- 確保水電已開通。〔待確認：你們是否要求〕

**下一步**
拿到報告後，依風險等級與位置，向建商提出修繕要求，修繕完成後安排複驗。〔核對＋官網：複驗為服務流程第 5 步〕

## 5. 社區團購驗屋怎麼運作？划算嗎？

- **slug**：`group-home-inspection-how-it-works`
- **分類**：驗屋知識
- **seoTitle**：社區團購驗屋怎麼運作？同建案多戶一起驗屋的好處與流程｜診斷筆記
- **metaDescription**：同一個建案多戶一起預約驗屋，達成戶數可享團報折扣。說明團報的運作方式、每戶如何各自預約，以及適合什麼情況。

**開頭**
同一個社區的住戶通常在差不多的時間交屋。〔核對〕多戶一起預約驗屋，對屋主和驗屋團隊都有好處：屋主可以享折扣，也能互相分享建商的常見缺失。〔核對〕

**運作方式（以官網目前規則為準）**
- 在官網「建案團報」找到你的建案，按「加入團報」。〔官網〕
- 每戶各自填寫預約，自己選日期與時段，不需要全部同一天。〔官網：你告訴我的團報規則〕
- 同建案報名戶數達到門檻，全團享團報折扣；目前的門檻與折數以官網公告為準（後台可調整，文章不要寫死數字）。〔官網〕
- 團報不與 LINE 好友折扣並用。〔官網〕
- 已取消的訂單不計入戶數。〔官網〕

**適合誰**
同建案、交屋時間接近的鄰居；想一起比較各戶缺失的社區群組。〔核對〕

**找不到你的建案？**
可以在官網提出新建案，審核上架後邀請鄰居一起加入。〔官網〕

**下一步**
先看官網團報專區有沒有你的建案，有的話直接加入；沒有就提出建案，並把連結分享給社區群組。〔官網〕
